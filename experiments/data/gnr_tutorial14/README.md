# Tutorial 14 data (fluorinated 12-AGNR, ab initio)

`Wannier2ViDES.H`, `Wannier2ViDES.xyz` and `n_Nc.dat` go here. They come from
Quantum ESPRESSO and Wannier90, run with the scripts of tutorial 14 of the
ViDES site:

    python3 experiments/ab_initio/run_tutorial14.py

Until they exist, the scenario `tut_gnr_fluorine` (R1) is reported as skipped.
